# Nova Assistant V2 — Smart Command Edition

Lightweight Android assistant with voice/text commands and flexible natural-language parsing.

## Features
- Voice commands
- Text commands
- Flexible phrasing (offline parser)
- Open URLs and video links
- Search Google
- Search YouTube
- Open popular websites
- Attempt to launch installed apps by label
- Multi-step commands separated by "and then", "then", or "and"
- Recent command history
- GitHub Actions APK build

## Examples
- I want to watch funny cat videos
- Find relaxing worship music on YouTube
- Take me to Facebook
- Can you open google.com
- Search Android tutorials and then open YouTube
- Open this link https://example.com
- Watch https://www.youtube.com/watch?v=VIDEO_ID

## Note
“Unlimited commands” means flexible natural-language phrasing, not unrestricted control over other apps.
Android security restrictions still apply. V2 uses structured actions and Android intents.
